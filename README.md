# yq Parser

## Overview

I always wanted a very simple JSON/YML parser. Nothing fancy, no extra windows and panes and modal popping up. The target I want to parse and a simple input.

## Keybinds

Set keybinds for `:YqParser` for both normal and visual mode.

If in visual mode, it will only use the selected lines, otherwise it will use the entire buffer.

## Requirements

- `yq`
- `snacks`
